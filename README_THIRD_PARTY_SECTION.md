## Third-party libraries and credits

VIA.WPF is built on .NET, WPF and the Microsoft Windows Desktop stack.

The project uses or wraps selected open-source libraries, including:

- CommunityToolkit.Mvvm by Microsoft and .NET Foundation contributors.
- GongSolutions.WPF.DragDrop by the GongSolutions.WPF.DragDrop contributors.
- FluentIcons.
- MahApps.Metro.IconPacks.
- System.Text.Json by Microsoft.

The `VIA.WPF.Icons` package provides a API over supported icon sources such as Fluent, Bootstrap, Font Awesome, Material, Material Design, Modern, File and Phosphor icons.

VIA.WPF is an independent project and is not affiliated with Microsoft, MahApps, FluentIcons, GongSolutions or any other third-party project.
